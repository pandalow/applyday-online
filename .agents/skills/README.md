# Project skills

These project-local skills were imported from
[`mattpocock/skills`](https://github.com/mattpocock/skills) at commit
`c55ee46073ed923f86ce59a5eb3b6d895095d1b7`.

The imported set contains the repository's stable `engineering` and
`productivity` skills. Content under `in-progress` and `misc` was intentionally
left out.

To configure the engineering workflow for this repository, invoke
`setup-matt-pocock-skills`.
